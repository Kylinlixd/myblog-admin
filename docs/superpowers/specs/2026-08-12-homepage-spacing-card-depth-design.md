# 首页间距与主题卡片层次设计

## 目标

优化首页理念区的上下节奏，并提升主题卡片的视觉层次，解决大标题行距过紧、卡片空白且风格单一的问题。

## 视觉调整

- 理念区增加路径元信息与三行主标题之间的垂直留白。
- 三行主标题使用更舒展的行距，保留当前暖色编辑风格和文字层级。
- 主题卡片改为桌面端轻微错落的网格布局，卡片高度和顶部偏移产生节奏差异。
- 每张卡片根据索引使用不同暖色光晕、编号和线性几何装饰，不引入外部图片资源。
- 卡片描述默认保持低对比度可读，悬停或键盘聚焦时增强；标题和主题名称始终清晰。
- 移动端恢复单列布局，取消桌面端错落偏移，卡片之间使用稳定间距。

## 实现边界

- 只修改 `src/views/blog/BlogHome.vue` 及其已有首页测试。
- 不修改接口、数据字段、路由和内容文案。
- 继续遵守 `prefers-reduced-motion`，不新增持续运行的动画。
- 主题卡片继续使用现有分类链接和 `--topic-index` 数据。

## 验证

- 首页源码测试覆盖新的间距、装饰节点和移动端规则。
- 运行全量 Jest 测试。
- 运行生产构建，确认 CSS 和模板编译成功。

# 移动端文件选择器信息密度设计

## 目标

降低移动端文件选择器的视觉噪音，让用户更快通过缩略图和选择态完成媒体选择。

## 已确认的产品行为

- 移动端文件卡片隐藏文件名和文件大小。
- 移动端保留缩略图、选中边框、选中标记、搜索、类型筛选、取消和确定操作。
- 桌面端继续显示文件名和文件大小，不改变现有文件识别能力。
- 文件列表数据、分页、筛选、选择和确认逻辑不变，只调整移动端展示层。

## 实现方案

使用现有 `.file-info` 结构和移动端媒体查询完成展示切换：

1. 在 `max-width: 640px` 下隐藏 `.file-info`。
2. 同一断点下移除 `.file-preview` 为文件信息预留的下边距，让缩略图网格更紧凑。
3. 不新增移动端模板、不复制文件数据、不改变 API 和选择逻辑。

## 验收标准

- 移动端源码包含只作用于 `.file-info` 的隐藏规则。
- 桌面端默认样式仍包含文件名省略和文件大小样式。
- 现有文件选择器测试全部通过，并新增布局回归断言。
- 生产构建成功，线上首页返回 200，发布后的前端资源与本地构建产物一致。

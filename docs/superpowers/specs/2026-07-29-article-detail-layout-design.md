# 文章详情页排版设计

## 目标

将文章详情页改造成温暖、专注、可持续阅读的文章界面，同时保留数字花园的技术气质，并让长文在桌面端和移动端都容易浏览。

## 设计决策

- 采用编辑型阅读作为主结构：米白阅读底、深色正文、高对比标题和舒适的窄正文列。
- 桌面端在正文右侧显示文章目录与阅读进度；移动端目录折叠到文章标题下方，避免挤压正文。
- 文章头部明确展示标题、摘要/类型、发布时间、阅读量、预计阅读时长和标签。
- 正文内容使用稳定的行高、段落间距、标题层级、引用块、代码块和媒体宽度规则。
- 评论区保持独立卡片，与正文形成明显分区；评论表单在移动端单列布局。
- 动效仅使用轻量进入动画和阅读进度变化，并遵守 `prefers-reduced-motion`。

## 范围

- 修改 `BlogDynamicDetail.vue` 的信息结构，增加目录数据与阅读进度计算。
- 修改文章详情专属样式，覆盖桌面、平板和手机断点。
- 保持现有 API、Markdown 渲染、评论提交和评论分页逻辑不变。
- 增加源代码回归测试，验证目录、元信息、移动端结构和 reduced-motion 样式存在。

## 不做的事情

- 不改变文章详情 API 或数据库模型。
- 不重写 Markdown 渲染器，不引入新的 UI 组件库。
- 不在本次工作中改动文章编辑后台。

## 验收标准

1. 桌面端正文宽度适合连续阅读，目录固定在正文右侧且不会遮挡内容。
2. 移动端无横向溢出，标题、元信息、正文、代码块和评论表单均可正常阅读。
3. 页面滚动时进度条随正文更新，目录锚点可跳转到对应标题。
4. 标签、阅读量、时间和阅读时长信息层级清晰。
5. 现有文章加载、评论加载、提交与分页行为保持不变。

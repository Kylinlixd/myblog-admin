# 夜蓝数字花园公共站设计规格

## 目标

把公共博客从“首页暗色、内页浅色且模板感明显”的割裂状态，统一成具有清晰记忆点的夜蓝数字花园。首页需要产生明显的视觉跃迁，分类、标签、动态、搜索、详情与关于页必须像同一产品，而不是相互独立的旧模板。

## 设计方向

- 主题基底采用深夜蓝光谱、冷白正文、钴蓝与青紫光作为重点色。
- `BlogLayout` 承担全站环境层：固定星雾、细网格、柔光团、低噪点和统一页头页脚。
- 动态背景使用 CSS 动画；滚动叙事使用项目已有 GSAP 与 ScrollTrigger，不新增依赖。
- 首页 Hero 使用 Cinematic Center 构图，两行标题“探索技术 / 无限可能”，桌面不超过两行，移动端不超过三行。
- 首页保留并加强 12 列 Bento，主卡 `7 × 2`、两个辅助卡各 `5 × 1`，总面积 24。
- 首页必须包含手动“创作宣言”轮播、无限跑马灯和横向手风琴，并加入文字擦除揭示与图片缩放淡出。
- 公共内页共享章节式页头、暗色内容卡、统一筛选器、空状态和分页视觉。

## 交互与可访问性

- 导航、卡片、按钮在 hover、active 与键盘 focus 时均有明确反馈。
- 路由切换保持轻量淡入上移，滚动特效不阻塞内容阅读。
- `prefers-reduced-motion: reduce` 时停止环境漂移并移除 GSAP 滚动绑定。
- 所有正文与交互文字保持可读对比度；装饰层设置 `aria-hidden` 且不接收指针事件。
- 移动端收敛背景光效、取消高成本滤镜，并保持 44px 触控目标。

## 内容约束

- 不编造读者评价；“创作宣言”轮播展示站点真实创作原则。
- 动态、分类、标签和搜索继续使用现有接口与数据结构。
- 删除公共动态页对外可见的调试按钮与测试数据入口。

## 验收标准

1. 首页与全部公共菜单页具有一致的夜蓝视觉语言。
2. 首页能明显看到动态背景、滚动文字揭示、图片缩放淡出、手风琴、跑马灯和手动轮播。
3. 桌面与移动端均无横向溢出，减少动效设置生效。
4. 现有公共站单元测试通过，并新增主题契约测试。

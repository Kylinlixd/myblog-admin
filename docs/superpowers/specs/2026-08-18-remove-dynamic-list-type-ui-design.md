# 移除动态列表类型界面

## 目标

动态内容允许混合附件，单一 `type` 已不再是管理员主动维护的属性。移除动态管理列表中与它有关的筛选和展示，避免出现误导性的 `text`、图文、音频或视频分类。

## 范围

- 删除动态管理筛选栏的“类型”下拉框。
- 删除动态管理表格的“类型”列及其表头筛选定义。
- 搜索请求不再携带 `type` 参数；重置搜索也不再设置该字段。
- 保留状态、分类、标签和关键词筛选，以及后端的 `type` 字段，保证现有 API 和数据兼容。

## 验证

- 列表挂载测试断言页面没有“类型”筛选或列。
- 搜索与重置测试断言请求参数不包含 `type`。

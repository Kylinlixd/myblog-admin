# 管理后台仪表盘数据叙事设计规格

## 目标

把现有“统计卡 + 柱状图 + 快捷入口”升级为更完整、层级更清楚的内容运营概览，同时只使用 `/api/stats/` 返回的真实数据。

## 信息架构

- 顶部增加欢迎概览带，包含当前日期、内容总量和主要发布动作。
- 四个 KPI 卡统一数值层级，并展示其占全部内容实体的比例条。
- 主区域采用 12 列网格：8 列近七天趋势、4 列内容构成与快捷动作。
- 趋势区保留无第三方图表依赖的可访问柱状图，增加总量、日均、峰值与清晰网格刻度。
- 内容构成以真实动态、分类、标签、评论数量生成比例条，不制造同比数据。
- 空状态、错误重试与加载骨架保持完整。

## 视觉方向

- 后台继续保持浅色工作台，而不是复制公共站暗色主题。
- 概览带使用克制的夜蓝渐变呼应品牌；数据卡使用白底、细边框、轻阴影。
- 通过字号、间距、比例条和局部色彩表达层级，不添加无意义装饰图表。

## 验收标准

1. 仪表盘出现清晰的概览带、KPI 比例、趋势、内容构成和快捷动作。
2. 所有派生数字均由现有接口数据计算。
3. 1080px 以下变为单列或双列，600px 以下保持可读和可触控。
4. 统计映射与趋势组件测试通过，并新增内容构成计算测试。

# 博客首页感官重设计规格

日期：2026-07-27  
范围：`/blog` 公开首页及与本次改造直接相关的前端冗余清理

## 目标

让访问者在首屏立即感受到“夜蓝数字花园”的独特气质，同时修正“探索技术 / 无限可能”两行标题的上下节奏、首屏空场和内容焦点单一问题。桌面端要有明显的视觉记忆点，移动端保持两行标题、清晰操作和稳定性能。

## 方案比较

1. **艺术化非对称首屏（采用）**：标题靠左形成主视觉，精选文章作为右侧悬浮内容窗口，并把精选媒体嵌入第二行标题。优点是变化明显、仍复用当前内容与 GSAP；成本和风险最低。
2. **居中电影海报式微调**：保留当前居中结构，只增强背景和卡片。实现最少，但无法根治单调与首屏纵向过长。
3. **Canvas/WebGL 粒子舞台**：视觉冲击最强，但会增加依赖、耗电、移动端降级和维护成本，不符合当前博客内容优先的目标。

## 视觉系统

- 保留夜蓝基底 `#060b14`，只使用冷蓝单一强调色和低饱和青色微光。
- 字体栈以 Outfit 为西文首选，中文继续使用系统无衬线字体，避免第三方字体网络阻塞。
- 首屏桌面为 12 列非对称网格：文案占 7 列，精选窗口占 5 列；移动端回落为单列。
- 标题固定两行，行高约 `0.88`，第二行和第一行之间使用可控间距；标题、说明、按钮使用 20–28px 的连续节奏，不再出现“字挤、内容散”。
- 第二行加入精选媒体窗口，作为“无限可能”里的视觉入口；无媒体时使用现有夜蓝渐变占位，不依赖新素材。
- 首屏后直接露出下一章节提示，消除当前精选卡片之后的大段空场。

## 动效与交互

- 首屏标题逐行揭示，精选窗口以轻微缩放和透视进入。
- 指针移动只驱动 CSS 变量和 GSAP 快速插值，形成低幅度光斑与卡片倾斜；触屏不启用倾斜。
- 滚动继续使用现有 ScrollTrigger：理念文字逐行 scrub；桌面文章导读固定在左侧，右侧文章卡片堆叠滚动。
- 所有可点击卡片保留图片缩放、边框亮起和按压反馈。
- `prefers-reduced-motion: reduce` 下取消倾斜、scrub、漂移和跑马灯，内容直接可见。

## 页面结构

- Navigation：沿用 `BlogLayout.vue` 的悬浮玻璃导航。
- Attention：重做 `BlogHome.vue` 首屏，使用艺术化非对称布局。
- Interest：保留并校正 12×2 bento，`7×2 + 5×1 + 5×1 = 24`，无空单元。
- Desire：保留理念文字、精选文章堆叠、主题手风琴和创作原则轮播。
- Action：保留主题跑马灯与最终 CTA。

删除无意义的编号元标签，例如 `SCROLL TO EXPLORE · 01` 和 `CREATION PRINCIPLES · 03`，改成可理解的中文引导或直接省略。

## 老旧文件审查规则

Git 最后修改时间早于 2025-07-27 只作为候选条件，不作为删除依据。删除必须同时满足：

1. 没有运行时、测试、路由、构建或部署引用；
2. 不是 Django migration、`__init__.py`、ASGI/WSGI、配置或入口文件；
3. 删除后测试与生产构建通过；
4. Git 历史足以恢复。

当前明确可清理项：未被模板使用的 Tailwind 入口、配置和 `tailwindcss-animate` 依赖；手写 UUID 工具可由原生 `crypto.randomUUID()` 取代。Breadcrumb、Pagination、公开头像、favicon、NProgress、后端 migrations 与启动入口均有真实用途，保留。

## 验证

- 新增或更新源码规则测试，锁定两行标题、非对称首屏、内嵌媒体、无编号元标签、reduced-motion 和零空洞 bento。
- 执行 Jest、Vite 生产构建和 `git diff --check`。
- 在 1080px 桌面、390px 移动端渲染截图，检查首屏节奏、文字可读性、横向溢出和下一章节露出。
- 对所有删除文件执行引用复查，记录保留与删除原因。

# Markdown 文件快速插入设计

## 目标

在动态编辑页的文件选择器中，让用户选择媒体文件后可以快速把引用写入 Markdown 编辑器，同时保留只关联媒体文件的原有操作。

## 交互

文件选择器底部提供两个动作：

- `插入正文`：将已选文件的 Markdown/HTML 引用插入编辑器当前光标位置，关闭选择器并聚焦编辑器。
- `仅关联媒体`：沿用现有确认流程，只更新动态媒体字段，不修改正文。

未选择文件时两个动作均不可执行或给出已有的选择提示。选择器关闭、取消和插入失败时不改变已保存数据。

## 内容格式

- 图片：`![文件名](文件地址)`。
- 音频：`<audio controls src="文件地址"></audio>`。
- 视频：`<video controls src="文件地址"></video>`。

多个文件按选择顺序逐行插入，并在引用之间保留一个空行。文件名用于图片替代文本，地址使用后端返回的 URL，不展示内部文件 ID。

## 组件边界

- `MarkdownEditor` 封装编辑器的插入能力，向父组件暴露单一的 `insertContent` 方法，并同步 `v-model`。
- `DynamicEdit` 负责根据所选文件生成引用、更新媒体关联字段、关闭选择器和恢复编辑器焦点。
- 继续使用 `md-editor-v3` 已有的光标插入 API，不增加依赖或另建编辑器状态。

## 验证

- 选择单张图片，点击「插入正文」，正文在光标处出现图片引用。
- 选择音频或视频，点击「插入正文」，正文出现对应 HTML 播放标签。
- 点击「仅关联媒体」，正文保持不变，媒体 URL 和文件 ID 仍正确更新。
- 多选图片按选择顺序插入多行。
- 运行相关单元测试和生产构建。

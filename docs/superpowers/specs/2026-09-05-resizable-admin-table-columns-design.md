# 后台列表可调整列宽设计

## 目标

让博客后台的动态、文件、分类、标签、评论和访问日志六个列表支持通过鼠标拖动表头分割线调整列宽。调整后的宽度保存在浏览器 `localStorage` 中，刷新页面后继续生效。

## 范围

- 覆盖四个 Ant Design Vue 表格：动态、文件、分类、标签。
- 覆盖两个自定义 `DataTable` 表格：评论、访问日志。
- 不修改博客前台页面。
- 不改变现有排序、筛选、行选择、固定操作列、横向滚动和移动端列裁剪行为。
- 选择框列不支持调整宽度。

## 方案

新增一个公共的可调整列宽组合式函数，由四个 Ant Design Vue 列表复用；自定义 `DataTable` 在组件内部接入相同的列标识、最小宽度和持久化规则。各列表提供独立且稳定的表格标识，防止不同页面的列宽互相覆盖。

不在六个页面中分别复制拖拽和存储代码，也不在本次改动中迁移表格组件。这样可以集中处理持久化和异常回退，同时避免影响 Ant Design Vue 表格已有的排序、筛选与固定列能力。

## 列标识与存储

- 每张表使用版本化、独立的 `localStorage` key。
- Ant Design Vue 列优先使用 `key`，其次使用 `dataIndex`。
- `DataTable` 列优先使用显式 `key`，其次使用 `prop` 或 `slot`。
- 存储值只包含列标识到像素宽度的映射，不保存业务数据。
- 初始化时将有效的持久化宽度合并到代码中的默认列定义。
- 缺失列、未知列、非数值、非有限数值和低于最小宽度的存储值均被忽略或校正。
- `localStorage` 不可用、读取失败或写入失败时静默回退到当前会话宽度，不阻断页面渲染和拖拽。

## 交互规则

- 可调整列在表头右侧显示可命中的分割线拖拽区域，并使用列调整光标。
- 默认最小宽度为 `72px`。
- 现有默认宽度小于 `72px` 的列可以保持原始初始宽度；用户开始调整后，新宽度不得小于 `72px`。
- 拖动过程中即时更新表格列宽，拖拽结束后持久化最终宽度。
- 表格总宽度超过容器时沿用现有横向滚动能力，不强制压缩其他列。
- 动态列表的桌面列和移动端裁剪列共享相同列标识；移动端只恢复当前可见列的宽度。

## 组件边界

公共组合式函数负责：

- 克隆并恢复列宽，避免直接修改调用方的静态列定义；
- 将宽度限制到允许范围；
- 更新指定列；
- 读取与写入持久化宽度；
- 在列集合变化时保留仍然有效的用户设置。

页面负责：

- 提供稳定的表格标识；
- 将公共函数返回的列交给表格；
- 将表格列宽变化事件交回公共函数。

`DataTable` 负责：

- 在表头渲染拖拽手柄；
- 处理指针移动与释放；
- 将恢复后的宽度同时应用到表头和数据单元格；
- 组件卸载时清理全局事件监听器。

## 测试与验收

先写失败测试，再实现以下行为：

1. 公共逻辑能恢复同一表格已保存的有效宽度。
2. 不同表格的存储互相隔离。
3. 调整后的宽度不会低于 `72px`。
4. 损坏或不可用的 `localStorage` 不会导致组件失败。
5. `DataTable` 渲染拖拽手柄，并在拖动后更新和保存宽度。
6. 六个列表均传入稳定的持久化标识并接入调整事件。
7. 现有完整 Jest 测试和 Vite 生产构建通过。
8. 本地浏览器验证至少覆盖一个 Ant Design Vue 表格和一个 `DataTable`：拖动生效、刷新后保持、不能缩至最小宽度以下。

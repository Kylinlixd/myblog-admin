# 管理端列表一致性设计

## 目标

在不改写管理业务逻辑、不引入新依赖的前提下，统一内容、分类、标签、评论、文件五个列表页面的标题、筛选、操作、表格和分页节奏，同时更新博客首页主文案并清理生产环境误导信息。

## 方案

采用共享壳层统一：扩展现有 `PageHeader` 组件以支持副标题和操作区；所有列表页使用同一标题组件；分类与标签表格补齐 `admin-table-card` 容器；评论页继续使用现有通用列表组件，但删除与全局工作区样式冲突的局部内边距。管理端侧栏移除“本地开发 / API 已代理到 8000”状态块。

不采用全部列表改写为同一表格实现，因为这会扩大回归面；也不采用纯 CSS 覆盖，因为它不能解决缺失页面标题和结构语义不一致的问题。

## 视觉与交互

- 标题采用 24px 主标题、简短副标题与右侧操作区，窄屏改为纵向排列。
- 筛选区、工具栏、表格卡片沿用已有 `admin-workspace.scss` 设计令牌。
- 菜单保留深蓝工作台结构和 50px 可点击高度，移除无效环境信息。
- 首页主标题固定为两行“探索技术的 / 无限可能。”，保留现有首屏动画和响应式布局。
- 不新增悬浮装饰、渐变文字、图标库或动画依赖。

## 验收

- 五个管理列表均出现共享标题与副标题。
- 分类、标签、内容、文件使用统一表格卡片表面；评论通用表格继续匹配该表面。
- 移动端标题、筛选和操作按钮不横向溢出。
- 侧栏不再显示本地开发提示。
- 首页主文案准确替换，既有单元测试和生产构建通过。

# 管理后台列表动作一致性设计规格

## 目标

解决动态、分类、标签、文件和评论列表中的操作按钮颜色、尺寸、间距和危险态不一致的问题，让所有菜单下的列表形成同一套高密度工作台语言。

## 设计与实现

- 在现有 `admin-workspace.scss` 中定义唯一的 `.table-row-actions` 与 `.row-action` 契约。
- 所有行内动作统一为 `small`、弱底色、同一圆角和最小高度。
- 编辑、审核等主要动作使用蓝色弱底；查看、下载、复制、拒绝等普通动作使用中性弱底；删除使用红色弱底。
- 危险操作只在确认后执行，保留现有 Popconfirm 与权限逻辑。
- 不创建只包一层按钮的新组件，不引入设计系统依赖。

## 验收标准

1. 五个核心列表均使用相同类名和按钮尺寸。
2. 操作按钮不再出现实心蓝色与实心红色混排。
3. 窄屏下动作区可换行但不覆盖内容。
4. 新增源码契约测试，确保后续页面不会重新分叉。

## 五、把“系统在线”改成真实服务状态

- 文案建议“服务正常 / 正在检测 / 连接异常 / 会话已过期 / 未连接网络”。它表示当前浏览器到后台服务的连接，不能宣称数据库、磁盘、对象存储全都健康。
- 新建后台专用 `GET /api/system/health/`（路径为拟新增），使用认证及后台权限，返回最小数据：status=ok、checked_at。若本轮只实现 API 连通性，弹层明确“仅检查后台 API 连接”。不返回版本、目录、数据库地址或环境变量。
- F/src/components/common/ServiceStatus.vue + F/src/composables/useServiceHealth.js 负责展示与检测；请求可单独放 F/src/api/system.js。进入后台立即检查，可见且在线时每 60 秒检查，5 秒超时，无自动多次重试叠加；请求未结束不再发起。
- 标签点击弹层展示检测范围、上次检测时间、请求往返耗时、手动重试；耗时包含网络，不能叫服务器处理时间。
- document.hidden 时停轮询，回到前台立即检查；路由内页切换不重新建多份计时器，退出后台时清理并取消未完成请求。
- navigator.onLine 只提供断网提示，不能单独证明后端正常。401 依现有会话策略处理，区分会话过期与服务故障；403 显示无权限，不能写成服务器宕机。失败没有新结果时标记旧数据过期。
- 健康检查不加入业务 PV/UV、IP 活跃和风险画像计数，避免这个新轮询污染之前统计；登录页和公开博客不启动轮询。手机显示紧凑状态图标并保留可点击文字说明/无障碍名称。
- 验证正常/超时/5xx/断网/401/403/回到前台/退出清理；保证不出现失败时仍挂绿色“正常”。

- 已拒绝/待审父节点下的后代公开列表暂不展示；审核撤回时整支隐藏，恢复审核后重新计算可见数。建议先保留现有父节点删除 CASCADE 行为，在后台删除前显示会连带删除多少后代并确认，不暗改历史删除语义。
- 公开列表、回复列表、reply_count、commentTotal 共用可见性规则。访客共享 guest，不把“我提交过”推断成整个 guest 账号可见；待审核内容只保留当前提交者本地回执，不能让所有访客看到。
- 查询先过滤公开内容，select_related/prefetch 或根索引减少 N+1，不一次递归返回所有后代。保留当前公开评论限流和审核机制。
- 本轮互评默认继续沿用游客昵称/邮箱身份，不假装游客昵称已经实名认证；后台身份标识只来自真实权限。
